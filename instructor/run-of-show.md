## Cut list, in order

1. Hall of fame: one presenter, not three (−6)
2. Ex 1 becomes a whole-room vote (−6)
3. Ex 7 becomes a whole-room walk-through (−5)
4. Module 2 demo jumps straight to the full prompt (−4)

**Never cut:** Ex 4, Ex 6, the bake-off, Ex 10's own-prompt check, or the
capstone build.

## If something breaks

| Problem | Do this |
| --- | --- |
| A learner's tool won't load or is blocked | Pair them with a neighbour; try another of the three tools at the break |
| Room Wi-Fi fails | Run demos from a phone hotspot; exercises continue in pairs on working devices |
| A demo gives an unexpected result | Use it. Every demo's notes say what to do either way |
| Free-tier message limit reached | Switch to one of the other two tools; the prompt transfers |
| Someone pastes real confidential data | Quietly ask them to delete the chat; repeat the ground rule to the room without naming anyone |
| Running very early | Use the extra-time list in [schedule.md](../schedule.md) |
