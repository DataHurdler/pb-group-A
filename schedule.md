## The day's thread

Each learner's own prompt grows all day, so the capstone is a finish, not a
fresh start:

**Exercise 4** (draft 1, Module 2) → **Exercise 6** (three rounds of
iteration, Module 3) → **Exercise 10** (privacy check, Module 5) →
**Exercise 11** (final, reusable version, Module 6) → **Exercise 12**
(presented).

## If the day runs long: cut in this order

1. Closing hall of fame goes from three presenters to one (−6).
2. Exercise 1 becomes a 4-minute whole-room vote instead of card sorting (−6).
3. Exercise 7 becomes a 3-minute whole-room walk-through (−5).
4. Module 2 demo jumps straight from the bare prompt to the full one (−4).

**Never cut:** Exercise 4, Exercise 6, the bake-off, Exercise 10's own-prompt
check, or the capstone build. These carry the day's goal.

## If there's extra time

1. A second bake-off round with a harder brief (+15).
2. Let every table send a capstone to the hall of fame (+10).
3. Exercise 6 stretch: try the same prompt in a second AI tool (+5).
