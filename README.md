# Prompt Engineering for Work

A one-day, in-person workshop on AI and LLM prompt engineering for novice to
entry-level professionals: 6.5 instructional hours, 15–25 learners, no coding
or AI experience assumed. Learners use the free versions of ChatGPT, Claude, or
Copilot.

**The goal:** by the end of the day, each learner can write clear, structured
prompts, evaluate and refine outputs, and apply prompting to one real task from
their own job.

## The day at a glance

| Time | Block |
| --- | --- |
| 8:30 | Opening |
| 8:45 | 1 How AI tools work, and what they can and can't do |
| 9:45 | 2 Anatomy of a good prompt |
| 10:45 | *Break* |
| 11:00 | 3 Techniques: examples, step-by-step, iteration |
| 12:00 | *Lunch* |
| 1:00 | 4 Checking outputs: hallucinations, bias, verification (with the prompt bake-off) |
| 2:00 | 5 Using AI responsibly: privacy, confidentiality, workplace policy |
| 2:45 | *Break* |
| 3:00 | 6 Capstone: build and present a prompt for a real task |
| 4:00 | Closing |
| 4:30 | *End* |

Every module runs the same way: warm-up, concept (15 minutes or less), live
demo, hands-on exercises (at least 40% of the module), then 10 minutes of
share-out and questions.

## Design principles

- **Plain language.** Every term is defined the first time it appears.
- **Hands-on.** 12 timed exercises take 43% of the day; share-outs take
  another 15%.
- **One thread through the day.** Each learner's own prompt is drafted in
  Module 2, refined in 3, privacy-checked in 5, and finished in 6.
- **Made-up data only.** Every example is fictional, and learners use invented
  details for their own tasks.
- **Tool-neutral.** Techniques work on any of the three tools' free versions.
